Bienvenido al manual de usuario de GobeBio. Esta guía está diseñada para ayudar a los administradores y personal de Recursos Humanos a utilizar todas las funcionalidades del sistema de manera efectiva.

La documentación está organizada siguiendo el flujo de trabajo natural, desde la configuración inicial hasta la generación de reportes.
